# SQL-Date-Functions-Assignment
-This project focuses on SQL Date Function exploring how to manipulate,format,extract,and calculate date and time values,it demonstrate how  SQL date functions help  organise  data ,analyse trends ,and generate meaningfull insights from time based records ,through practical exercise i developed my understanding of working with dates in SQL
-The purpose of the assignment was to learn how to manipulate,extract,format and calculate dates from different datasets

*OBJECTIVES*
-Extract specific date infomation such as months,quarters and days
-Identify the beginning and end of a month 
-Calculate the number of days between two dates 
-Convert text values into date formats
-Format dates into readable formats
-Understand how date functions are used in real world data analysis 


*SQL DATE FUNCTIONS COVERED*
-MONTH()-extracts the month from a date
-DAYNAME()-returns the name of the day
-QUARTER(0-extracts the quarter of the year
-DATEDIFF()-calculates the difference between two dates
-CURRENT_DATE()-returns the current date
-LAST_DAY()-returns the last day of the month 
-DATE_TRUNC()-truncates a date to a specificied time unit
-TO_DATE()-converts a value into a specified pattern
